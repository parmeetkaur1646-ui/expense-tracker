# Expense Tracker

---

## 📌 Project Description

The **Expense Tracker** is a simple and interactive web application that allows users to manage their daily expenses.

Users can:

* Add new expenses
* View added expenses
* Delete expenses
* Automatically calculate the total expense amount

The project uses **HTML for structure, CSS for styling, and JavaScript for functionality and dynamic updates.**

---

## ✨ Features

* ➕ Add a new expense
* 📝 Display expense details
* 🗑️ Delete an expense
* 💰 Automatically calculate the total amount
* 🔄 Dynamically update the expense list
* 📱 Responsive and user-friendly interface
* ⚡ Interactive functionality using JavaScript DOM manipulation

## 🚀 How to Run the Project

1. Download or clone the project.
2. Open the project folder in **VS Code**.
3. Open `index.html` in your browser.
4. Enter an expense name and amount.
5. Click the **Add Expense** button.
6. The expense will appear in the expense list.
7. The total amount will be calculated automatically.
8. Use the **Delete** button to remove an expense.

## 📚 JavaScript Concepts Used

### DOM Manipulation

DOM manipulation is the process of using JavaScript to access, modify, add, or remove HTML elements dynamically.

### Event Listeners

Event listeners are used to perform an action when a user interacts with the webpage, such as clicking a button or submitting a form.

### Arrays

An array can be used to store multiple expense records.

### Functions

Functions are used to organize reusable operations such as adding expenses, deleting expenses, and calculating the total.

### Dynamic Calculation

JavaScript calculates the total amount whenever an expense is added or deleted.
